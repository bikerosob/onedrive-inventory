1. Autenticação Microsoft

Este aplicativo não usa a sessão do Graph Explorer. É necessário um registro de aplicativo próprio com plataforma Single-page application (SPA), tipo de conta Personal Microsoft accounts only e permissão delegada Files.Read.

Abrir Microsoft Entra
O Client ID não é secreto. Só ele é salvo neste navegador; tokens ficam no armazenamento de sessão da biblioteca Microsoft.
Aguardando configuração. Você pode experimentar o modo demonstração sem login.
Instruções de cadastro, caso ainda não tenha um Client ID
  1. Abra Microsoft Entra → Identity → Applications → App registrations → New registration.
  2. Nome sugerido: Fabio OS OneDrive Inventory. Escolha Personal Microsoft accounts only ou a opção que inclua contas Microsoft pessoais.
  3. Em Authentication → Add a platform, selecione Single-page application e registre a URL exata exibida acima. Não escolha “Web”.
  4. Em API permissions, configure Microsoft Graph → Delegated → Files.Read. Não conceda Files.ReadWrite nem permissões de aplicativo.
  5. Copie apenas Application (client) ID no campo acima. Nunca crie nem cole um client secret, senha, código de recuperação ou access token nesta página.
  6. Se o Entra negar o cadastro porque sua conta não tem um diretório com permissão para registrar aplicativos, pare: precisaremos de outro método autorizado. Não contrate serviços por causa deste teste.
