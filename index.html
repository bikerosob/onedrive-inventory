1. Autenticação Microsoft

Aplicativo Microsoft Entra já cadastrado. A autenticação usa OAuth 2.0 com PKCE, sem scripts externos e sem client secret.

O Client ID é público. O access token existe somente na memória da aba aberta; o verificador PKCE temporário fica no sessionStorage durante o retorno.

3. Inventariar OneDrive inteiro

Varredura a partir da raiz, incluindo subpastas próprias. Atalhos compartilhados/remotos ficam fora do escopo. Somente metadados: nomes, caminhos, tamanhos, datas e hashes informados pelo Microsoft Graph.

Checkpoint automático após cada página no armazenamento local deste Safari (IndexedDB). Não guarda tokens e não publica dados no GitHub. Mantenha esta aba aberta durante a leitura; se houver interrupção ou expiração do login, é possível retomar. Os dados salvos no Safari incluem nomes de arquivos privados — não use em dispositivo compartilhado.
